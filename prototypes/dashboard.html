Google Play

Fully automatable through the Play Developer API: listing text, art, builds and test tracks.

Steps

  1. ✓
    Developer account
    One-time fee and identity check, done by you.
    by hand
  2. ✓
    App created in Play Console
    Package name must match Unity.
    by hand
  3. !
    Service account for the API
    Create it in Google Cloud, grant it access in Play Console, save the JSON key outside the repo and point PLAY_SERVICE_ACCOUNT_JSON at it. Play Console ↗
    by hand, once
  4. !
    Upload key
    Created locally by the desk; Play App Signing keeps the release key.
    desk
  5. ✓
    Listing text
    Pushed from Store listing.
    API
  6. 2
    Art
    Feature graphic and 1 phone screenshot missing.
    API
  7. ·
    Internal test release
    Uploads the release AAB to the internal track.
    API
  8. ·
    Closed test before production
    New personal accounts must run a closed test with enough testers for a fixed period before production access. The desk tracks the count and days.

Log

Every run writes a short summary to Store/Logs/latest.txt (not committed), so problems can be read and fixed quickly.

[12 Nov 10:42] Refresh all Unity: product name ok · version differs (desk 12, Unity 11) · android package differs Play: listing pushed (title, short, full) · art: feature graphic missing; phone shots 1/2 Play: PLAY_SERVICE_ACCOUNT_JSON not set → cannot upload builds Steam: not set up (no app id) Epic: not set up Rules: Play listing limits checked against current docs (title 30, short 80, full 4000) Result: 3 blocking, 2 warnings
